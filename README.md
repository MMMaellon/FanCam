A VRChat world prefab for complex streaming/recording cameras. Designed for idol concerts and vtuber liveshows.

## Download

### Full Install

Requires a package manager like [VRChat Creator Companion](https://vcc.docs.vrchat.com/) or [ALCOM](https://vrc-get.anatawa12.com/en/alcom/).
It also requires downloading my entire VCC listing.

1. Press the big **Add all to VCC** button on my [full VCC Listing](https://mmmaellon.github.io/MMMaellonVCCListing/) to add all of my prefabs to your package manager.
2. In your package manager, add FanCam to your project. All dependencies should get installed automatically.

### Custom install

If you don't want to download all of my prefabs, visit this prefab's [individual package listing](mmmaellon.github.io/FanCam) or download the .unitypackage file from the [releases page](https://mmmaellon.github.io/MMMaellonVCCListing/). You'll need to install all the dependencies manually.

#### Dependencies
[SmartObjectSync](https://github.com/MMMaellon/SmartObjectSync)
