# FanCam

Manager for switching between multiple in-world cameras in VRChat worlds.
Was originally designed for use in my Vtuber world commissions.

# Ask questions on my [Discord Server](https://discord.gg/S5sDC4PnFp)

# Basic Instructions

1. Place one or more **FanCam** prefabs in your scene and configure their behavior
2. Place one or more **FanCam Target** prefabs in your scene. (Optional) 
3. Place a **FanCamManager** prefab in your scene and complete the setup on the FanCamManager Component.
